# Introduction

Welcome to the Screenshot API Service documentation. This service provides a robust API to capture screenshots of web pages. Users can easily sign up, obtain an API key, and integrate screenshot capabilities into their applications.

## Features

Our service offers a range of features designed for ease of use and efficiency:

*   **User Registration and Login:** A simple process to create and manage your account.
*   **API Key Generation:** Securely generate and manage your API keys from your dashboard.
*   **Screenshot API Endpoint (`/api/take`):** A straightforward endpoint to request screenshots.
*   **Usage Tracking:** Monitor your usage, with a generous limit of 100 screenshots per user per month.
