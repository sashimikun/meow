# Getting Started

This guide will walk you through the first steps to begin using the Screenshot API service.

## Prerequisites

To start using the API and capture your first web page screenshot, you'll need an `access_key`. Here’s how to get one:

1.  **Sign Up:** If you don't have an account yet, you'll need to register. You can sign up for an account on our web portal, which is typically available at the root URL of the service (e.g., `http://localhost:5000/` if you're running it locally, or the production URL if you're using a deployed version).
2.  **Sign In:** Once your account is created, sign in using your credentials.
3.  **Retrieve Your Access Key:** After successfully signing in, navigate to your dashboard. Your unique `access_key` will be displayed there. This key is essential for authenticating your API requests.

Keep your `access_key` secure, as it identifies your account and tracks your usage.

With your access key in hand, you're ready to explore the API functionalities, which are detailed in the API Reference section.
