# Getting Started

This guide explains how to start using the Screenshot API to capture web pages.

## Prerequisites

1.  **Sign Up and Obtain an Access Key:**
    *   First, you need to create an account. You can sign up on the web portal, which is typically available at the root URL of the service (e.g., `http://localhost:5000/` if you are running it locally).
    *   Once you have successfully signed up and signed in, your unique `access_key` will be displayed on your dashboard. This key is essential for making API requests.

    Keep your `access_key` secure, as it is used to authenticate your API requests and track your usage.

*(The API endpoint details, request parameters, example requests, and error responses from the original README.md will be covered in the "API Reference" section of the documentation later.)*
